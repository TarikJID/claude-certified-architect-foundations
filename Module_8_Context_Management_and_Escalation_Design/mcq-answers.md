## Task statement 5.2

**Q1 [5.2]** Correct: C. Tests: 5.2-K1, 5.2-S4.
- Why: When the policy does not cover a request, the agent escalates. Silence is not permission.
- A wrong: Approving by guessing can make a wrong promise.
- B wrong: Refusing by guessing is the same mistake in the other direction.
- D wrong: The customer's mood is not a reason to hand over.

**Q2 [5.2]** Correct: A. Tests: 5.2-K2, 5.2-S2.
- Why: A clear request for a person is honored at once, with no investigating first.
- B wrong: Fixing first ignores what the customer asked for.
- C wrong: Asking for an explanation delays a clear request.
- D wrong: The model's confidence rating is unreliable, and it does not matter when the customer asked for a person.

**Q3 [5.2]** Correct: D. Tests: 5.2-K2, 5.2-S3.
- Why: No request for a person and a simple problem: acknowledge, offer to fix it, and escalate only if they ask again.
- A wrong: Being upset alone is not a reason to hand over.
- B wrong: Ignoring the frustration is poor service.
- C wrong: The agent can check the order, so refusing is wrong.

**Q4 [5.2]** Correct: B. Tests: 5.2-K3, 5.2-S1, 5.2-K1.
- Why: Mood ratings and self-rated confidence do not show how hard a case really is. Clear triggers plus worked examples steer the agent reliably.
- A wrong: More mood-based handovers make the same mistake worse.
- C wrong: Self-rated confidence stays unreliable however it is asked for.
- D wrong: Effort alone is not a trigger; a five-step case that fits the policy should not be handed over.

**Q5 [5.2]** Correct: C. Tests: 5.2-K4, 5.2-S5.
- Why: Two matches need another detail from the customer, not a guess.
- A wrong: Most recent activity is a guess and can refund the wrong person.
- B wrong: List order is also a guess.
- D wrong: Refunding both pays someone who should not be paid.
